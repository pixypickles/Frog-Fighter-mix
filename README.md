# カエルファイターMIX v0.2

水中格闘 + 地上格闘を、ターン制の拠点争奪マップでつなぐ試作版です。

## 基本構想
- 5対5
- 一本道の「マス目」ではなく、拠点と拠点を道で結ぶすごろく/ネットワーク型
- 1回の移動は隣接地点まで。現段階では複雑な機動力パラメータなし
- 敵駒と同じ地点へ入るとアクションバトル
- 水域の遭遇 → water/ の水中戦
- 陸地の遭遇 → ground/ の地上戦
- 戦闘HPは将来的に戦略マップへ持ち越し
- 中間拠点：ターン開始時 +12 HP
- 本拠地：ターン開始時 +22 HP
- 敗北：本拠地へ送還し待機後復帰、というルールを次段階で戦闘結果と接続

- アスモデウス（水専門）

### 地上専門
- アザゼル（トンボ）
- ベリアル（クモ）

アザゼル/ベリアルを含めた「10人から交互に5人を取るドラフト」は次段階候補。
固定軍で始める場合は、地上専門2人をどちらの軍へ入れるか、または交代枠にするかを決める必要があります。

## v0.2
- 自由フィールドマップから拠点・道方式へ変更
- 陸地/水域を地図上に共存
- 駒を選ぶと移動可能な隣接拠点と道が点灯
- 中立拠点の占領
- ターン交代
- 水専門キャラは陸地へ侵入不可
- 敵駒と遭遇すると地形に応じた既存バトルへ遷移
- ミニゲームなし

## v0.3
- ベルゼブブ軍をプレイヤー操作からCPU操作へ変更
- プレイヤーはカワズ軍のみ操作
- 同じ地点の駒表示を3体固定から、4体以上でも円状に重ねて表示する方式へ変更
- 水中戦に入る前は「横持ちしてください」
- 地上戦に入る前は「縦持ちしてください」
- 端末の向きが合えば自動で戦闘へ進み、ボタンでも開始可能
- 地上戦はジャンプ版の縦画面を維持

## v0.4
- 戦略マップを「半分水」から、陸地中心に池が点在する地形へ変更
- 西の池 / 大きな池 / 深みを水中戦エリアとして配置
- 森の祠・古い井戸を、本線から1つ外れた行き止まりの回復拠点として追加
- 遭遇戦の残りHPを戦略マップへ返す処理を接続
- 勝者はその地点に残り、敗者は本拠地へ送還して2ターン回復待ち
- 拠点にいる味方は自軍ターン開始時にHP18回復
- MIX遭遇戦ではキャラ選択を飛ばし、戦略マップ上の対戦カードで自動開始
- 水中戦は横持ち、地上戦は縦持ちを維持

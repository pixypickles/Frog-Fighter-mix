# カエルファイターMIX v0.2

水中格闘 + 地上格闘を、ターン制の拠点争奪マップでつなぐ試作版です。

## 基本構想
- 5対5
- 一本道の「マス目」ではなく、拠点と拠点を道で結ぶすごろく/ネットワーク型
- 1回の移動は隣接地点まで。現段階では複雑な機動力パラメータなし
- 敵駒と同じ地点へ入るとアクションバトル
- 水域の遭遇 → water/ の水中戦
- 陸地の遭遇 → ground/ の地上戦
- 戦闘HPは将来的に戦略マップへ持ち越し
- 中間拠点：ターン開始時 +12 HP
- 本拠地：ターン開始時 +22 HP
- 敗北：本拠地へ送還し待機後復帰、というルールを次段階で戦闘結果と接続

### 地上専門
- アザゼル（トンボ）
- ベリアル（クモ）

アザゼル/ベリアルを含めた「10人から交互に5人を取るドラフト」は次段階候補。
固定軍で始める場合は、地上専門2人をどちらの軍へ入れるか、または交代枠にするかを決める必要があります。
